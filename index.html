Kenapa cara ini menghemat Google Drive?

File tugas (gambar, PDF, video, PPTX) di-upload ke penampungan gratis luar (Imgur, Catbox.moe, GitHub). Kamu cukup memasukkan link-nya ke dalam daftar tugas di bawah atau tabel Excel.

Cara Memasukkan Data Tugas:

  1. Upload file tugasmu ke penampungan gratis dan salin link-nya.
  2. Buka file index.html ini menggunakan Text Editor (Notepad / VS Code).
  3. Cari bagian const assignmentsData = [...] di bawah kode JavaScript.
  4. Tambahkan atau edit data tugas sesuai format yang ada, lalu save dan upload ulang ke GitHub-mu!
